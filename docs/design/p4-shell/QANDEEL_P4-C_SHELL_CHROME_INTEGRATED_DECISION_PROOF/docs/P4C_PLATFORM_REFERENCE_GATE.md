| Guidance | Effect on P4-C |

## 3. What is platform-owned vs QANDEEL-owned

- **Platform-owned:** the status bar, the home indicator, system permission prompts, the OS badge on the app icon, real
  Dynamic Type / Bold Text / Increase Contrast / VoiceOver / TalkBack behaviour. P4-C draws none as Product.
- **QANDEEL-owned:** every candidate on the boards — its place, its form, its words and its state channels.

## 4. No platform source is promoted over canon

Where the platform differs (selected-tab tint; red badges), QANDEEL's frozen law stands and the candidates obey it. No
candidate is proposed because a platform prefers it; the platform is cited only where it bears on a real tradeoff.
