# V9 — Design Rationale

Concise by task mandate. No manifesto.

---

## Carried from V5B

- **Unambiguous reading order.** Every surface has one, including the scene: peer
  statements → each reading's own material → what they share → what each stands on and
  what is missing.
- **A composition that cannot be read as a quantity.** V5B's real achievement. V9 keeps
  it and makes it checkable: one ground value, one material type size, asserted live.
- **Low explanation burden.** Measured the way V7 measured it — interface-explaining
  characters as a share of visible characters on Deep Analysis, S2, desktop:
  **V5B 13.6%, V6 28.5%, V9 11.6%** (with both readings' ground opened, the state
  comparable to the other two; 17.0% as the scene rests, where the reader's own content
  is still folded away).
- **Clear correction state, clear unknown state, predictable controls, calm
  conversation, truth-first hierarchy.**

## Carried from V6

- **Single-instance shared material** — the rule, not the geometry. The record renders
  once and each reading's role is stated at the record. **Extended to same-role
  sharing**, which V6's channel did not cover and which the runtime makes the common
  case (S5).
- **Fragment-as-sentence.** Recorded material is the user's own language with a margin,
  never a card. Three bordered-and-rounded elements in the whole scene.
- **Provenance-as-disclosure-control.** The metadata line is the button; the accounting
  and correction live inside it.
- **The seat**, re-solved. A named unknown is still an intentional place that always
  names what is missing — but it is now marked by a *broken rule* instead of a recessed
  plane, so "missing" is no longer rendered as lower than "established".
- **The anchor**, with its display leading fixed (1.5, never 1.3).
- **The RTL paged stage**, with the shared thing physically between the peers and the
  active pane surviving every re-render.
- **The restraint gradient across surfaces** — V6's most under-recognised achievement.
- **The motion discipline** and **the dialog accessibility model**, both strengthened:
  native `<dialog>` gives a real trap and a genuinely inert background, and a disclosure
  now keeps focus on its own control instead of dropping it to `<body>` — a defect V7
  recorded against *both* predecessors.

## Deliberately rejected

- **The four-plane monotonic luminance ladder.** V7's most serious finding: four steps
  of one visual variable mapped onto four semantic categories is an ordinal scale, and
  it read as a ranking of epistemic states the runtime does not contain. Replaced — see
  below.
- **The opening.** It carried no information the channel did not already state, and the
  "giving way" was never composed. Deleted. What replaces it is not a device but an
  *alignment*: each role line sits directly beneath the shared record in its own
  reading's column track, on that column's exact margin position.
- **The fixed central channel.** The shared record no longer sits in a third geometric
  column on a darker ground. It is a row that **crosses** the two peers.
- **The stretch-derived empty ground and the sentence justifying it.** The stage is now
  exactly as tall as the pane you are on (shared pane 270px against a tallest pane of
  593px), so the void cannot arise and nothing has to claim it was deliberate.
- **Permanent dominance of the shared record.** Asserted in both directions now.
- **The full territory system**, the opening device, Matn, Threshold, Wizn.
- **V6's 26px sliver of the neighbouring pane on mobile.** Good in a Latin layout; in
  RTL it exposes the ends of Arabic lines and costs the measure long Arabic needs.

## The answer to V7's one open question

V7 closed by naming a single prerequisite: **a non-ordinal encoding of "different
ground".**

V9's answer is **one ground and a nominal margin.** Everything QANDEEL holds sits on the
same paper and carries a rule on its start edge; only the *kind* of rule changes — one
rule, two rules, a broken rule, brackets. A solid rule, a doubled rule and a broken rule
are different kinds of line, not different amounts of one thing, so there is no scale to
climb. It survives grayscale trivially because it carries no value at all, it reaches
assistive technology as words, and it needs no disclaimer, which is why the surface can
carry no ranking vocabulary at all — not even to deny it.

## How the four screens share one grammar

The same three things travel across all four surfaces, and nothing else does:

1. **The margin.** QANDEEL's own turns in Conversation carry the same start-edge rule
   that recorded material carries in Live Context and in the scene. That single mark is
   Conversation's only spatial trace.
2. **The record's identity.** «مرتاح مع الفريق…» is one sentence with one provenance
   line, recited inside a turn in Conversation, standing as an item in Live Context, and
   standing once under a doubled rule in the scene. Depth increases; the object does not
   change.
3. **The reader's own foreground.** One press, one device, identical in Live Context and
   in the scene — brackets, an outdent, full ink, everything else receding.

Continuity comes from shared information structure and one interaction logic. There is
no morph, no trail, no glow and no cinematic transition anywhere.

## Biggest remaining visual-language uncertainty before V10

**Whether a single ground can carry a whole product, or whether it will need a second
surface value once real volume arrives — and if it does, what that value is allowed to
mean.**

One ground is what makes V9's grammar quantity-proof, and it is what the margin system
is built on. But the whole build is currently one paper with one accent-free ink family,
and its restfulness is partly the restfulness of a short fixture. Six months of dense
sessions will press for a second surface — for the drawer, for a sticky region, for a
focused item — and the moment a second value appears, the question V7 asked returns:
is it a *place*, or is it a *level*? V9 deliberately refuses the second value rather
than answering that, which is the right move for a grammar test and an open question
for a visual language.

Two smaller ones worth naming for V10:

- **The desktop scene is two equal columns plus a crossing row.** The composition is
  defensible and it is not a triptych, but it is the closest V9 comes to the broadsheet
  default, and it is undefined for three or more peer readings — which the runtime does
  not prevent.
- **Live Context is still improved by craft rather than by spatial intelligence.** V7
  said this of V6 and it remains true here. The truth constraint that nothing may be
  placed nearer than anything else leaves the surface very little legitimate spatial
  work to do; what V9 adds is that it now visibly belongs to the same world.
