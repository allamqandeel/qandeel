## The vendored schemas

`schemas/2025.10/**` is **not this package's work**. It is the official DTCG 2025.10 JSON Schema
set, retrieved from the specification's own repository and pinned because `designtokens.org` is
unreachable from this environment. Every file carries its SHA-256 **and its git blob SHA-1**, the
latter recomputed locally and matched against the blob sha the GitHub tree API reports for the
official repository. `tools/b4r-schema.mjs` re-checks all of it (S-01) before validating anything,
because a vendored authority that can be edited is not an authority.

## Packaging

`tools/b4r-package.ps1` builds the archive, re-hashes every predecessor archive — **including
I-08B3.1-B4, which this package corrects and must leave untouched** — and refuses to write if any
has moved. It then runs content guards against the shipped documents and token files.
