# B4_SURFACE_EARNING_TEST

**I-08B3.1-B4.7.** The production form of the B0 Earning Test.

Short enough to use in code review. That is the specification, not a stylistic preference: a test
nobody can hold in their head during a pull request is a test that runs once, at design time, on the
screens somebody remembered to check.

---

## Before a Surface may appear, all five must hold

### 1. REMOVAL
**Delete the container entirely. What functional understanding breaks?**

If the answer is "nothing", the Surface is not earned. Looking less tidy is not functional
understanding breaking.

### 2. CHEAPER MECHANISM
**Why can position, spacing and type alone not do this job?**

Position, spacing and type are always cheaper than a Surface, because they add no material. If they
can do it, they win. "It reads better with a box" is not an answer; it is the question restated.

### 3. ROLE
**Exactly one of APPARATUS, ASIDE, PASSAGE or FIELD must apply.**

If the answer is "none of them", it is decoration. If the answer is "two of them", the composition
is wrong before the Surface is — a layer that is both anchored-nonmodal and blocking has not decided
what it does to the World.

### 4. NON-SEMANTIC
**Does this Surface assert anything about the analysis inside it?**

It may not rank, group, dignify or qualify analysis. A Surface that means something is cardification
with a justification. Specifically it may never encode confidence, evidence, importance, recency or
FAR/MID/NEAR — enforced at the token layer by INV-08.

### 5. BOUNDARY DUTY
**Does something across this boundary genuinely need marking? Name the duty.**

Every edge must name a functional or accessibility duty. An edge with no duty is texture. Class S is
load-bearing only; Class O defaults to none and exists only if it independently passes the Edge
Removal Test.

---

## And where bounded ANALYTICAL content appears: the Substitution Test

Carried from B0R, unchanged.

**Replace the content with a placeholder. Does the container still have a reason to exist?**

If it does not, the container exists **because of** the analytical content — which means the Surface
is asserting something about the analysis, and SG-1 forbids it.

This is the test that catches the most persuasive cardification, because that kind always arrives
attached to real, important content. An excerpt inside an ASIDE passes: the ASIDE exists because
something was raised from a citation, and it would still exist if the excerpt were three words long.
A "key finding" in a box fails: remove the finding and the box has no reason to be there.

---

## Two removal tests that are not this one

- **Edge Removal Test** — for a Class O organisational edge. Remove the edge; something functional
  must break. Default is **none**.
- **Card Removal Test** — remove the container from a screen that has many of them. If the screen
  still works, every one of them was cardification.

---

## In review, as a comment

> Which of the four roles is this, and what breaks if I delete it? If the answer involves the words
> "grouping", "organisation", "hierarchy" or "importance", it is cardification. If the content could
> be a placeholder and the container would still be right, it is a Surface. If it could not, it is a
> card.

---

## What this test is not for

It does not adjudicate radius, spacing, type or copy. It answers exactly one question — **may a
Surface exist here** — and answering more than that is how an earning test turns into a style guide.
