# I-08B3.0-E3 — Review Manifest

**Status: READY FOR DESIGN DIRECTOR TYPOGRAPHY FREEZE REVIEW.**
E2 is not frozen. E3 is not approved. Typography is not canonical. I-08B3.0 is not closed.

The typeface is **not** under test — Estedad v8.5 is accepted. This package tests the proposed type
**system** around it, and was built to look for failure.

---

## How to read this package

1. **`review/TYPOGRAPHY_SYSTEM_OVERVIEW.png`** — the contract as stated, set, plus the single-ink
   (monochrome) check and the measured clearance table. Start here.
2. **`review/TYPOGRAPHY_FAILURE_BOARD.png`** — where the contract becomes weak. Six cases, plus an explicit
   list of the stress conditions that were tried and **passed**, so their absence means something.
3. **`review/ACCESSIBILITY_SCALE_MATRIX.png`** — the 100 / 130 / 160 / 200 % argument, under Android 14's
   real nonlinear curve.
4. `docs/I-08B3.0-E3_TYPOGRAPHY_SYSTEM_REPORT.md` — everything the boards cannot show, including the answers
   to the ten evaluation questions and the seven proposed bounded corrections.

Every board is rendered at device pixel ratio 2, so open them at 100 % and expect them to be larger than the
screen. Board chrome is set in the OS UI face and a chrome grey so it can never be mistaken for specimen text.

## Font provenance — `fonts-info/`

No font binary is redistributed. `SOURCES.lock.json` carries the source of record, byte length and SHA-256;
`LICENSE-OFL.txt` is the licence as distributed with the family.

## Tools — `tools/`

Node 24 plus Chrome. No npm packages, no network at build time.

| File | Role |
|---|---|
| `system.json` | **The single source of truth** — the proposed contract, all seven proofs' content, the diacritic cases, and the controlled surface. Every board and every measurement reads from this one file. |
| `scale.mjs` | Android 14+ nonlinear font scaling, transcribed from AOSP `FontScaleConverterFactory` / `FontScaleConverterImpl`, with a self-check that fails the build if the tables drift. |
| `ui.mjs` | The controlled environment, the restrained product components, the per-role CSS, and the font fingerprint guard. |
| `render.mjs` | Chrome invocation: two-pass sizing, forced greyscale antialiasing, font-fingerprint assertion, overflow guard, blank guard. |
| `measure.mjs` | Shaped-text measurement in the engine. Emits `MEASUREMENTS_rendered-text.json`. |
| `collision.mjs` | Rendered-pixel line-collision test. Emits `MEASUREMENTS_line-collision.json`. |
| `build-boards.mjs` / `build-boards2.mjs` / `build-all.mjs` | The fourteen boards. |
| `check-render.mjs` | Palette-ramp fairness guard across everything in `review/`. |
| `png.mjs` | PNG decode/encode, crop, nearest-neighbour upscale, ink coverage. `node:zlib` only. |
| `crop.mjs` | Inspection helper for cutting 1:1 regions out of a board. |
| `font-facts.mjs` | Reads the facts §3 states straight out of the font's tables. Emits `MEASUREMENTS_font-tables.json`. |
| `package.mjs` | Writes the zip directly — local header / central directory / EOCD — and re-parses its own output to verify it. |
| `verify-zip.mjs` | Decodes every board out of an *extracted* copy of the shipped zip, which is what a reviewer actually opens. |

| Stop conditions | **None triggered** |

Four defects in this package's own harness were found and fixed rather than shipped — a font that was never
actually applied, a guard that shifted the page it was guarding, board chrome that silently lost its styling
to a quoting bug, and a provenance hash computed over a buffer that an in-place byte-swap had already
corrupted. Two claims this package initially made were **withdrawn** when measurement contradicted them. All
six are documented in §17 of the report.
