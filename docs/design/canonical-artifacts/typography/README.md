# Typography — I-08B3.0-E3 Typography System

Estedad v8.5 is the accepted face, and this is the type **system** around it: the eight roles, their
size and leading pairs, and the measured Arabic floors.

- `i-08b3.0-e3/tools/system.json`: the role table the whole package was generated from.
- `i-08b3.0-e3/docs/I-08B3.0-E3_TYPOGRAPHY_SYSTEM_REPORT.md`: the decision record and its evidence.
- `i-08b3.0-e3/docs/MEASUREMENTS_*.json`: the measured metrics.
- `i-08b3.0-e3/fonts-info/`: the licence (SIL OFL 1.1) and the binary's release tag and SHA-256.
  **No font binary is included.** Its identity is recorded instead.

Provenance, lifecycle and exclusions: [`SOURCE-PROVENANCE.md`](SOURCE-PROVENANCE.md).
