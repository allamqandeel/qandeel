# C3_LUXURY_BOUNDARY

**I-08B3.1-C3.6.** The luxury-risk production boundary.

---

## 1. The finding, frozen from C1 and C2

**Black + Brass inherently carries some luxury plausibility.** That is a property of the combination,
not of a mistake anyone made, and it does not go away.

**The solution is NOT to weaken Brass until it disappears. The solution is APPLICATION DISCIPLINE.**

---

## 2. The evidence that coverage is the right variable

C2's `F06` accumulation capture is the load-bearing result in the whole C track, and it is worth
restating precisely because it is counter-intuitive.

It takes the **identical** restrained body — the same `#A58E6F`, measured by C1R at 2.3–3.2× *less*
chromatic than the golds in its 192-palette census — and gives it five permission classes at once: an
identity mark, the navigation family, functional controls, dividers, and an analytical mark.

**The result is unmistakably a gold theme.**

Nothing about the colour changed. **Coverage, not chroma, produces the failure.** Which means the
defence cannot be a quieter colour, and any proposal to make the body weaker is answering a question
that the evidence says is not the question.

---

## 3. Production failures

Each of these is an application decision, not a colour decision. Each has an invariant guarding the
token output, and each is forbidden for a reason rather than by taste.

| Failure | Why it is tempting | Guard |
|---|---|---|
| **Brass borders around dark cards** | reads as "premium", costs nothing | **I-08** |
| **Brass typography** | warms a long reading screen | **I-07** |
| **Brass dividers as decoration** | cheap, repeatable, looks intentional | **I-08** |
| **Brass on every functional action** | the platform's own guidance points this way | **I-15** |
| **Brass analytical nodes** | the important finding feels like it deserves it | **I-06** |
| **Brass premium entitlement** | entitlement feels like identity | **I-05** |
| **Metallic gloss** | makes the material look "real" | structural — the character is subtractive-only, and no gradient, ramp or highlight exists in the specification to reach for |
| **Repeated ornamental lines** | rhythm without content | **I-08** |
| **Large decorative Brass areas without identity purpose** | fills space | the permission test in `C3_ICONOGRAPHY_MATERIAL_CONTRACT.md` §5 |

### 3.1 The four preserved rules

```
BRASS NEVER ENCLOSES.
BRASS NEVER SETS TYPE.
BRASS NEVER GLEAMS.
BRASS NEVER ACCUMULATES INTO GOLD UI.
```

**"Never gleams" is the only one of the four that is a measurement rather than a rule.** The character
is subtractive-only by construction, and across fifteen rendered widths and four device-pixel-ratio
conditions the brightest pixel it produces equals the body's own lightness exactly. The other three
are rules, and they are kept by the token architecture having nowhere to express them.

### 3.2 "Never accumulates", interpreted

**It means ONE COHERENT MATERIAL STORY. It does not mean one instance per screen.**

This is the interpretation that matters, because the wrong one is the more natural reading and it
would undo the Director's decision. P2 puts the material on five navigation icons plus the mark on
every screen — six objects — and that is *not* accumulation. It is one family reading as one family.

Accumulation is **five permission classes**, not five instances of one class. `F06` is five classes.

## 4. What the production measurement shows

Measured off C3's own reproduction rasters:

| Environment | chromatic share of ink |
|---|---|
| Utility / System UI | **6.64 %** |
| Personal Conversation World | 3.93 % |
| Living Analysis Map | 3.51 % |
| Deep Analysis Reading | **2.51 %** |

And the result that speaks directly to accumulation risk:

**The four environments and the four interaction states contain exactly 2109 chromatic pixels each.
Identical, not similar.** The material's footprint does not grow between screens, and it does not grow
when something is selected. Under P2 as specified, accumulation is not a tendency that has to be
resisted screen by screen — it is structurally absent, because the permission classes do not multiply.

**The Utility screen remains the concentration point**, at 6.64 %, and it is the environment with no
analytical geography to distinguish it from any other dark settings screen. That was C2's central
trade and C3 does not change it: it is the screen a luxury or generic relabel would find easiest.

## 5. External corroboration, and a correction to C2's record

The `frontend-design` skill installed on this host names, for calibration, three looks that current
AI-generated design clusters around. The second is:

> *"a near-black background with a single bright acid-green or vermilion accent"*

**C2 recorded this as corroboration that QANDEEL is structurally adjacent to a current AI default.
The structural adjacency is real and stays on the record.**

But C2's summary was looser than the sentence, and the difference matters. The sentence names a
**bright** acid-green or vermilion accent. Living Brass is the opposite of bright: C1R measured it
2.3–3.2× less chromatic than census golds, and C3 measures it at Oklab C 0.0516 against a frozen
reading ramp that reaches 0.0153.

**On the axis the sentence actually names — brightness and saturation — QANDEEL is distinguished
rather than implicated.** On the axis of structure — near-black ground, one warm thing — it is
adjacent, and that adjacency is a real reason for the discipline in §3.

Both halves are recorded. Overstating the corroboration would be as wrong as ignoring it.

Note also that the same skill names *"content chopped into identical rounded cards"* as another
current default — independent corroboration of a rule QANDEEL already holds.

---

## 6. The boundary, stated as a production rule

```
If a QANDEEL composition reads as luxury, the response is to REMOVE A PERMISSION CLASS,
never to weaken the body.
```

The body is `#A58E6F` and C3 has no mechanism to change it. There is no second body in the token
system, no opacity ladder, no lightness ladder and no chroma ladder — invariants **I-09**, **I-10** and
**I-12**, each with a probe. **The recalibration response is not merely forbidden; it is unavailable.**

That is deliberate. A specification that left a quieter Brass within reach would be a specification
whose luxury defence could always be satisfied by the one move the evidence says does not work.
