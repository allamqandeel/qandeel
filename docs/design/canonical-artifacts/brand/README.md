# Brand — I-08B2.5 Final Brand Asset Package

The production brand assets, byte-exact: the Q mark and wordmark masters, the iOS and Android app
icon sets, and the monochrome and light-background derivatives, together with the deterministic
build source that produced them.

- `i-08b2.5/masters/`: the four approved master SVGs. Future builds start here.
- `i-08b2.5/app-icon/`: the canonical app icon (`APP_ICON_B_DARK_LUMINOUS.svg`, the frozen I-08B2.4
  Variant B, carried byte for byte), the iOS `AppIcon.appiconset` and the Android `res/` tree.
- `i-08b2.5/derivatives/`: monochrome, light-background and PNG exports.
- `i-08b2.5/source/`: the generator (`README_REGENERATE.md` gives the order).
- `i-08b2.5/docs/`: the final asset report and review manifest.

Provenance, lifecycle and exclusions: [`SOURCE-PROVENANCE.md`](SOURCE-PROVENANCE.md). No asset was
altered, re-exported or optimised.
