# QANDEEL — Canonical Artifact Index

**Status:** `PRESERVATION INDEX — LOCATOR ONLY. CREATES NO AUTHORITY.`

Read this before any major Product or design task. For each domain it answers four questions: where
the final authority lives, which hash proves it, what lifecycle state that authority has, and where
the original sealed package is.

- **Paths** are relative to `docs/design/canonical-artifacts/` unless they start with `docs/`.
- **Archives** live on the Product Owner's laptop under `E:\QANDEEL\QANDEEL PROJECT\` (written
  `…\` below), or, where marked **Library**, only in the project's ChatGPT Library, from which
  independent review recovered them for the PR #265 reconciliation (`reconciliation/`). None is in
  Git. Their SHA-256 is the identity to ask for.
- **Later amendments bind.** Each preserved source is the original final authority for its own
  phase. Where a later canonical record in this repository amends it, the later record wins. See the
  last section.
- **"Frozen per downstream ledger"** means the package describes itself as a candidate. Its freeze was
  a Director / Product decision made outside it, and that decision is recorded by the later packages
  that inherit it. The recording packages are named in each domain's `SOURCE-PROVENANCE.md`.
- **Upstream architecture authority** is not indexed here. Core Checkpoint v2, the Navigation Checkpoint
  (Stages 0–4), Stage 5, Stage 6 and Connected Worlds v2 CW2-00 … CW2-08 are located by
  [`docs/canonical-authority/CANONICAL_AUTHORITY_INDEX.md`](../../canonical-authority/CANONICAL_AUTHORITY_INDEX.md).
