## What VI-01 froze

- **Native bilingual authorship / transcreation.** Arabic and English are each authored as a
  product language. Neither is a translation of the other.
- **One Arabic product language for v1.** No second pre-authored chrome profile.
- **The Arabic register architecture.** `T1` chrome · `T2` QANDEEL's voice · `T3a` analysis
  chrome · `T3b` analysis prose · `T4` system.
- **Truth / semantic guardrails.** Copy may not claim understanding, agency, relevance or
  provenance that the runtime does not deliver.
- **Naming-minimization.** A concept gets a user-facing name only when the user needs one.
- **The gender policy.** No fixed Arabic string is masculine-as-default; neutrality is a
  constraint, not the copy objective.
- **The peer-scaling language constraints.** Identity is never ordinal, never positional,
  never "the other"; aggregate and region labels are count-independent; no peer is silently
  omitted, truncated away or made unreachable at any count.
- **Provenance and correction semantics.** Recorded material is not a transcription and is
  never typographically quoted as one; corrections are stated, not implied.
- **The accessibility language invariants.** Navigation position is an accessibility
  affordance supplied through native semantics, never authored product copy or identity.
- **The rejection-authority taxonomy.** `SEMANTIC / TRUTH HARD BAN` · `INTERNAL ONLY` ·
  `PRODUCT / STRUCTURAL REJECTION` · `CURRENT-VOCABULARY PREFERENCE`. A rejection's authority
  determines whether and how it may ever be revisited.
- **The exact core vocabulary marked `APPROVED`** in the final package.

## What VI-01 explicitly did NOT freeze

> `PROPOSED`, `OPEN`, `PROVISIONAL`, and ordinary microcopy may be refined in later
> visual/interaction/production work as long as the frozen semantic contract, runtime truth,
> accessibility contract and bilingual meaning remain intact.

A `PROPOSED` or `OPEN` entry is **not a defect**. It is the honest status for wording whose
naturalness or final form cannot be certified from the page, and the archived documents mark
each one in place.
