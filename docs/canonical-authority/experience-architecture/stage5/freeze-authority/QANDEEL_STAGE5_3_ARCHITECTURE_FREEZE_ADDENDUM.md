# A-01 — Anonymous Focus Transition eligibility is committed/stable only

Candidate class 4.1 is accepted only with this qualification:

> An anonymous focus-transition disclosure is Timeline-eligible only when the transition is a committed, historically legitimate semantic transition already entitled in `K(t)`.

A provisional / Emerging / pre-geographic focus shift is **not** a Timeline disclosure event merely because runtime attention temporarily moved.

Therefore:

- no marker is created from an unstable or provisional focus hypothesis;
- no Emerging Focus identity, destination, Thread name, or future Home locus is disclosed;
- if a transition is later committed as historically legitimate, only the anonymous fact of transition may be eligible;
- the identity and meaning of the transition remain MAP-ONLY;
- the marker's temporal address, if presented, derives from legitimate current-session `SP`;
- historical visibility remains gated by `K(TC)`.

This keeps Stage 3.5 Emerging Focus semantics intact and prevents the Timeline from publishing transient analytical processing.

The accepted boundary statement is therefore read as:

> **The current-session Timeline discloses temporal orientation and the minimum committed anonymous conversational structure needed for temporal legibility. It does not disclose analytical interpretation.**

# A-02 — D-36 is a non-enumeration requirement, not frozen control topology

The candidate's accessibility finding is accepted in substance:

> Future-relative-to-`TC` Moment structure must not be recoverable by enumerating focus stops or accessibility metadata.

However, wording such as **“single composite temporal control overall”** is not frozen as a physical/control-topology requirement.

Canonical meaning:

- no independently enumerable post-`TC` Moment stops;
- no focus order, labels, bounds, metadata, or child-control count may disclose future quantity or clustering;
- non-drag / discrete temporal navigation required by Stage 5.2 remains valid;
- the eventual Live-Edge vs latest-Moment solution may use one composite control, multiple explicit affordances, or another accessible structure, provided the no-enumeration firewall holds.

Final control topology remains part of OPEN-12 / later Experience + accessibility design.

# A-03 — D-20 is a disclosure rule, not a navigation-coordinate rule

`D-20` **post-TC non-metric reachability** is APPROVED.

Canonical interpretation:

> While `PINNED(TC)`, the **presented disclosure** of `TC < position ≤ LH` must not encode future-relative magnitude, subdivision, density, event count, or semantic structure.

The visible/nonvisual reachability affordance may state only that later current-session time exists/requires explicit navigation and may include the already-approved qualitative Live-meta.

But D-20 does **not**:

- redefine Stage 5.2 navigation grammar;
- define hidden pointer-to-time mapping;
- define keyboard increments;
- define coarse stepping;
- settle ordinal vs duration-proportional axis policy;
- require the temporal target to move under the user's pointer as Preview resolves.

Those remain outside this disclosure contract.

Any later interaction mapping must preserve Stage 5.2 and must not itself become a side-channel that exposes forbidden future structure before explicit Preview/commit.

# A-04 — Correction / Supersession remains MAP-ONLY

Architecture resolves the candidate's §4.3 review question:

> **Correction / supersession transitions remain MAP-ONLY for the Stage 5 current-session Timeline.**

Reason:

- their useful meaning is analytical rather than merely temporal;
- an anonymous correction marker has weak orientation value;
- a named correction marker reconstructs analytical narrative;
- a sequence of correction markers would move the Timeline toward an analysis feed;
- known historical lineage remains fully preserved and inspectable through the Map / Reading / Source-Provenance path.

This does not erase or downgrade superseded lineage. It only denies it a Timeline disclosure class.

# Accepted Stage 5.3 core

The following candidate directions are approved and frozen:

1. Timeline domain remains current-session only.
2. Timeline remains temporal orientation/navigation support; the Map remains the semantic world.
3. `FOLLOW_LIVE`, `PINNED(TC)`, and Preview have state-dependent disclosure.
4. Post-`TC` future structure is protected by a channel-independent no-hindsight firewall.
5. Post-`TC` extent is disclosed only as non-metric reachability while pinned.
6. Forward Preview may license disclosure only through the explicitly previewed `PTC`.
7. Backward commit/cancel withdraws disclosure no longer legitimate at the restored `TC`.
8. `SP` is the only legitimate current-session Track address source for any later-approved content marker.
9. `RTO`, `KF`, `VF/VT`, object age, Thread age, and Map position are not Track addresses.
10. Readings, relations, evidence participation, questions/information gaps, corrections/supersession, and other analytical interpretation remain MAP-ONLY.
11. Confidence-over-time is forbidden as a Stage 5 Timeline disclosure class.
12. Anonymous focus-transition structure is allowed only under A-01.
13. Aggregation is a neutral legibility construct only; never a canonical object, analytical weight, or navigation granularity.
14. Empty stretches remain neutral; geometry must not manufacture importance.
15. Live-meta while historical may communicate only qualitative continued-Live existence / route back, never magnitude, rate, identity, focus, location, or content.
16. Suspended `IF` naming remains knowledge-gated.
17. Visual and nonvisual/accessibility surfaces obey the same epistemic firewall.
18. Narrow/mobile projection reduces simultaneity, not truth.
19. Live Edge and latest absolute Moment must remain semantically distinguishable even at the same coordinate; final affordance remains open.
20. Stage 5.3 freezes no final Timeline styling, motion, implementation, renderer, schema, or code.
