## What this answers

> When the authoritative historical projection `K(t)` changes, how does the Living Analysis Map truthfully represent the then-legitimate state of the same world — without moving canonical geography, leaking future knowledge, confusing absence with dormancy or depth, or breaking inspection and orientation?

## The claim, in one line

**Truth changes; geography does not.** Stage 5.4 decides **presence, state, contextual availability and retrievability** — never position.

## The mechanism that carries most of the contract

**`pos(e) = f(e)`** — canonical position is a function of the entity and its own establishment, **never of the set present at `TC`**. Because no entity's position ever reads the projection's membership, historical compaction is **impossible by construction**, not merely forbidden — and AT-01, AT-02, AT-06 and AT-24 fall out of it together. What remains to police is only presentation-level substitutes (clustering, alignment, emphasis), which the contract names explicitly.

## Four more load-bearing moves

| | Claim | Effect |
|---|---|---|
| **Gate order** | knowledge → context → validity → **depth last** | Depth-withholding is reachable only after every temporal gate passes, so it can never be confused with absence. |
| **Depth-invariance vs depth-monotonicity** | temporally unavailable ⇒ absent at *every* depth; depth-withheld ⇒ present at *some deeper* depth | Makes AT-13 checkable rather than assertable. |
| **Uniform, reason-free absence** | a distinguishable absence would itself announce the future object | Reconciles AT-21 and AT-22 — dormant is *presence with state*, unknown is *not present at all*. |
| **`IF_ref` vs `IF_render`** | the retained reference confers no rendering authority | Exact Return stays exact while the Map refuses to render unavailable truth. |

## Rulings applied

- **RULING-01** — the frozen Stage 3 Emerging representation is **preserved**, not reinvented: non-established, non-owning, non-locating, valid only while Emerging is legitimate. Home-locus persistence is scoped **establishment-onward**, so at a pre-establishment `TC` there is *nothing to borrow*.
- **RULING-02** — confidence is a versioned analytical property: only then-valid confidence, only at entitled depth, never as geometry; Stage 5.3's Timeline prohibition untouched.
- **RULING-03** — inspected, not assumed: `PREVALID` is **unreachable for analysis-derived versions** (`KF == VF` by construction) and **undetermined — flagged, not invented** for world-fact validity. AT-12's premise therefore does not arise for Readings.
