# QANDEEL Living Analysis Map

## Experience Architecture v1 — Stage 0 Final Freeze Review

---

# A. Consolidated Stage 0 Experience Architecture v1

## A1. Core Experience Model

QANDEEL Living Analysis Map treats a conversation as an **unfolding semantic world** rather than a static analysis page, topic list, graph, or chronological transcript.

The world is built from persistent canonical conversational and analytical objects that can be explored through:

- spatial navigation,
- semantic zoom,
- stable Conversation Threads,
- analytical inspection,
- source/provenance inspection,
- and a coupled current-session Timeline.

The central architectural rule is:

**Canonical truth is stable; representation changes with context, zoom, navigation, and time.**

Spatial presentation must never create analytical meaning that is not independently grounded.

---

## A2. Conversation Thread Model

A **Conversation Thread** is a persistent, navigable locus of conversational attention.

It is not merely:

- a keyword,
- a detected topic,
- an entity,
- a person name,
- a turn,
- or an interesting inference generated by QANDEEL.

A Thread becomes persistent only when it acquires **independent conversational attention or user-addressable significance**.

### Thread lifecycle

A conversational subject may pass through:

**Mention / Entity → Emerging Focus → Established Thread**

Once Established, the same Thread may become:

**Active → Dormant → Reopened**

without losing identity.

### Emerging Focus

An Emerging Focus may appear provisionally while the conversation develops.

It does not yet receive:

- a permanent Neighborhood,
- a stable canonical Home Anchor,
- or permanent geography.

QANDEEL-generated Readings, Unknowns, or Questions may strengthen an Emerging Focus, but analysis alone cannot establish permanent geography.

### Established Thread

Persistent geography begins only when the Thread becomes Established.

Once established:

- its canonical identity persists;
- interruption does not destroy it;
- dormancy does not remove it;
- reopening returns to the same Thread.

### Refinement versus reframing

A Thread's label or description may become more precise without changing identity.

A genuine shift to a new independently addressable conversational focus creates a **new Thread** rather than silently rewriting the original.

Therefore:

**Refinement preserves identity. Reframing may establish a new identity.**

---

## A3. Canonical World Components

The minimum canonical Conversation World contains the following categories without prematurely defining the final Stage 1 taxonomy.

### Conversation Thread

Persistent navigable conversational locus after establishment.

### Record / Utterance

Canonical source-bearing material from the current conversation, retaining the necessary speaker, session position, and conversational context.

### Memory

Canonical source-bearing material originating from prior context and recalled or used in the current conversation, with inspectable provenance.

### Event

A canonical grounded world object representing something that occurred, occurs, or is expected to occur.

An Event is **not automatically a direct source object in the same epistemic sense as Record/Utterance or Memory**.

Stage 1 determines whether a particular Event is observed, normalized, derived, inferred, or otherwise characterized.

### Reading / Hypothesis

A canonical interpretive object representing QANDEEL's analytical reading.

A Reading remains distinct from its grounding and never becomes Source Truth merely because the user zooms deeper.

### Unknown

A canonical representation of a meaningful unresolved knowledge gap.

### Question

An inquiry object that may help investigate an Unknown or advance understanding.

Question and Unknown remain distinct.

---

## A4. Three distinct relational contracts

The architecture strictly separates:

### Conversation Transition

Records how conversational attention moved between Threads across the current conversation.

It expresses:

**where attention moved**

not:

**what analytical relationship exists.**

### Grounded Semantic Relation

A canonical analytical relationship between Threads or other canonical objects supported by real grounding.

Its final taxonomy belongs to Stage 1.

### Evidence Participation

When a Record, Event, Memory, or other evidence-bearing underlying object participates in grounding a Reading, that participation must preserve the canonical identity of the underlying object.

Stage 0 does **not** decide whether Evidence remains a first-class runtime object or is represented through another runtime contract.

Therefore:

**Conversation Transition ≠ Grounded Semantic Relation ≠ Evidence Participation.**

None may be inferred purely from spatial proximity or presentation geometry.

---

## A5. Canonical Identity and Shared Objects

One canonical object may participate in multiple Conversation Threads.

For example, one Memory may be relevant to:

- Work,
- Ahmed,
- Relationship with Ahmed.

This does not create three Memories.

The architecture remains:

**one canonical object → multiple contextual participations / appearances**

rather than:

**one context → one duplicated object.**

### Contextual Appearance

A Contextual Appearance is a non-semantic projection of one canonical object inside a particular Thread Neighborhood.

It:

- does not create another canonical identity;
- does not create another source;
- does not independently carry analytical truth.

### Cross-Thread Shared Anchor

Multiple Contextual Appearances are the default.

A shared object becomes an explicitly visible cross-thread shared anchor only when its shared identity itself is materially important to understanding:

- cross-context structure,
- analytical bridging,
- or recurrent cross-thread use.

Even then, it remains a representation of the same canonical object.

Its presence does not by itself establish a semantic relation between the participating Threads.

---

## A6. Thread Geography

Every newly Established Thread receives one stable **canonical Home Anchor in Conversation-World space**.

The anchor is not fixed to screen pixels.

Its rendered position may change because of:

- camera movement,
- pan,
- semantic zoom,
- viewport transformation,
- responsive layouts,
- device-specific projection.

None of these changes violate Object Permanence.

### Placement inputs

A new Thread's canonical placement uses:

1. conversational origin;
2. appropriate available outward-growth territory;
3. future spatial legibility.

It must not be determined by:

- semantic similarity clustering,
- connection count,
- grounded relation count,
- force-directed graph organization.

### Conversational Origin

Conversational Origin indicates where new conversational growth came from.

It helps select an appropriate growth frontier.

It does **not** prescribe:

- exact adjacency,
- angle,
- distance,
- edge,
- direction,
- or linear sequence.

Therefore:

**Origin tells us where growth came from; it does not prescribe geometric form.**

`Work → Ahmed → Relationship` must not automatically become a spatial timeline or chain.

---

## A7. Meaning of Spatial Proximity

Spatial proximity carries **no analytical meaning by default**.

Two Threads may be near each other because of:

- navigation continuity,
- historical growth,
- available territory,
- presentation legibility.

That does not imply:

- causation,
- similarity,
- support,
- contradiction,
- hierarchy,
- shared subject,
- or any other semantic relation.

Analytical relationships require independently grounded canonical relations.

Thus:

**Geography determines where things live.**
**Grounded semantics determine what relationships actually mean.**

---

## A8. Append-Oriented Growth and Object Permanence

Conversation World growth is append-oriented.

When a new Thread becomes Established:

- it claims suitable available world territory;
- previously Established Home Anchors are preserved;
- the world grows outward rather than continuously optimizing itself.

Established Threads are not moved merely because:

- a new Thread appears;
- a semantic relation is discovered;
- a shared object appears;
- another region becomes denser.

### Stable after establishment

The following remain stable:

- canonical Thread identity;
- canonical world-space Home Anchor;
- historical establishment origin;
- prior established geography;
- canonical shared-object identities.

### May adapt

The following may evolve without violating Object Permanence:

- Neighborhood extent;
- internal arrangement;
- contextual appearances;
- labels/refined descriptions;
- density;
- semantic-zoom disclosure;
- grounded relations;
- available outward-growth use.

Therefore:

**Anchor is permanent; Neighborhood expression is adaptive.**

---

## A9. Convergence Without Destructive Merge

Two Established Threads may increasingly share:

- Records,
- Events,
- Memories,
- analytical material,
- or grounded relations.

This does not destroy either Thread.

Convergence may produce:

- additional shared participation;
- new Grounded Semantic Relations;
- or, if the intersection itself gains independent conversational attention and satisfies Stage 0.1 establishment criteria, a new third Thread.

Established Threads are not destructively merged merely because later understanding reveals strong overlap.

---

## A10. Spatial, Conversational, Analytical, and Temporal Structures

The Living Analysis Map maintains four distinct structures.

### Spatial Structure

Where Established Threads and canonical world objects are situated.

### Conversational Structure

How conversational attention moved between Threads.

### Analytical Structure

What grounded analytical relations, Readings, Unknowns, Evidence Participation, and other analytical structures exist.

### Temporal Structure

When things participated, became relevant, or became analytically available during the current conversation.

These structures may correlate, but none is automatically derived from another.

Specifically:

**Spatial location does not imply Conversation Transition.**

**Conversation Transition does not imply Grounded Semantic Relation.**

**Grounded Semantic Relation does not dictate canonical geography.**

**Temporal proximity does not itself imply analytical connection.**

---

## A11. Protection Against Generic Graph Architecture

Threads are persistent navigable Neighborhoods, not abstract graph nodes.

Canonical geography must not be organized by:

- force-directed graph logic;
- semantic similarity;
- connection count;
- relation count;
- graph centrality;
- automatic repositioning when relations change.

This prohibition applies to **canonical truth and geography**, not to implementation aesthetics.

Later stages may use local presentation techniques such as:

- collision avoidance,
- local packing,
- contour relaxation,
- label separation,

provided they do not:

- move canonical Home Anchors;
- rewrite canonical geography;
- or imply unsupported semantics.

---

# A12. Semantic Zoom Contract

Semantic Zoom changes **representation and information disclosure**, not canonical identity.

The same canonical object remains the same object from Z0 through Z3.

The governing rule is:

**Deeper zoom reveals; it does not rewrite.**

Less detail must never mean different truth.

---

## Z0 — Conversation World

Z0 answers:

**What meaningful conversational territories exist, and how has this conversational world formed?**

The user may understand:

- Established Threads;
- their persistent existence;
- current conversational focus;
- major conversational topology;
- meaningful grounded cross-thread structure when appropriate;
- broad presence of analysis, memories, or unresolved material where useful;
- provisional Emerging Focus when currently forming.

Z0 does not expose full:

- source text;
- detailed Evidence;
- provenance;
- analytical internals;
- Unknown details;
- full Question content.

---

## Z1 — Thread Neighborhood

Z1 answers:

**What participates in this Thread, and what is currently understood or unresolved here?**

The user may understand:

- Thread identity and refined context;
- relevant Records/Utterances;
- Events;
- Memories;
- Readings/Hypotheses;
- Unknowns;
- Questions;
- relevant shared objects;
- grounded relations;
- evidence participation at the appropriate level.

Full Source Truth and complete provenance remain deeper.

---

## Z2 — Reading / Analysis Object

Z2 answers:

**What exactly is this interpretation, unresolved point, or analytical object, and how is it grounded?**

For a Reading, the user can inspect:

- the interpretation itself;
- relevant Threads/objects;
- grounding structure;
- evidence participation;
- Unknowns;
- Questions;
- grounded analytical relations where applicable;
- provenance summaries.

If the selected object is instead a Record, Event, or Memory, Z2 exposes how that canonical object participates in the analysis without changing its ontology.

---

## Z3 — Source Truth

Z3 answers:

**What source material or inspectable grounding does this analysis actually rest on?**

For Record/Utterance and Memory, this can expose direct source material and provenance.

For Event, it exposes inspectable grounding appropriate to the Event without falsely treating every Event as direct source material.

A Reading remains a Reading at Z3; the user inspects its sources or grounding rather than turning the Reading itself into Source Truth.

---

## Semantic-Zoom invariants

Across all levels:

- canonical object identity remains unchanged;
- Contextual Appearances remain projections of canonical objects;
- source-bearing/world/analysis object distinctions remain intact;
- deeper representation may reveal uncertainty, provenance, or grounding;
- higher levels may summarize but may not contradict deeper truth.

---

# A13. Orientation State

Orientation is a first-class experience state.

The system conceptually maintains:

- **Spatial/Semantic Inspection Focus**
- **Semantic Depth**
- **Session Temporal Cursor**
- **Session Live Head**
- **Navigation Context**
- **Follow Live Focus state/intent**

These concepts remain independent where required.

---

## A14. Spatial Context versus Semantic Focus

The user may be spatially situated in one Thread Neighborhood while deeply inspecting another canonical object reached from that context.

Therefore:

**Spatial Context** = where the object is currently being inspected from.

**Semantic Focus** = which canonical object is currently being examined.

Deep inspection must retain a recoverable relationship to the Conversation World.

---

## A15. Inspection Lineage

Moving inward through Z0 → Z1 → Z2 → Z3 creates a reversible **Inspection Lineage**.

This is navigation history, not an assertion that the world ontology itself is hierarchical.

Returning:

**Z3 → Z2 → Z1 → Z0**

restores the exact contextual route through which the user arrived rather than resetting them to an unrelated position.

---

## A16. Required Wayfinding Capabilities

Stage 0 freezes four orientation capabilities without prescribing their eventual UI:

### Context Path

What am I inside / inspecting?

### Focus History

Where was I before this navigation action?

### World Overview

Where is my current context relative to the complete accumulated Conversation World?

### Persistent Thread Landmarks

Established Threads remain findable through their stable Home Anchors even when Dormant.

---

## A17. Lost-User Recovery

Spatial recovery changes navigation state, not canonical world state.

The experience must conceptually allow recovery to:

- current Live Conversational Focus;
- current or previous Inspection Context;
- a legible World Overview.

The camera/navigation may move.

Canonical geography does not.

---

## A18. Direct Addressability

Established Threads and inspectable canonical objects are directly addressable.

Direct navigation must retain previous Orientation State in Focus History.

For a shared object:

- existing contextual origin may determine which Contextual Appearance is entered;
- absent such context, navigation addresses the canonical object itself and exposes its participating contexts.

No arbitrary “primary Thread” is invented.

---

# A19. Live Conversational Focus

Live Conversational Focus indicates only:

**where current conversational attention is directed.**

It does not mean:

- importance;
- rank;
- centrality;
- analytical strength;
- confidence;
- permanent priority.

Moving Live Focus never reorganizes canonical geography.

---

# A20. Primary Timeline Scope

The primary Conversation Timeline represents the chronology of the **current conversation/session only**.

Stage 0 does not define:

- global history;
- multi-session chronology;
- long-term temporal navigation across all past conversations.

---

# A21. Three temporal concepts remain distinct

## Session Temporal Position

When an object participated or became relevant within the current conversation.

For example, an old Memory recalled at `12:40` gains a current-session temporal footprint at `12:40`.

## Source / Referenced Temporal Origin

When the underlying material originally occurred or refers to, when known.

A Memory may originate three months ago while participating in the current session at `12:40`.

The old source time does not move the primary Session Timeline cursor outside the current session.

## Analysis Availability / Knowledge Time

When QANDEEL actually formed or made an analytical object/state available.

For example:

- source evidence spoken at `04:20`;
- Reading formed at `11:50`.

Historical inspection at `04:20` must not show the `11:50` Reading as though QANDEEL already possessed it.

---

# A22. Session Timeline ↔ Map Contract

Map and Timeline are two coupled projections of the same current conversation.

### Map answers

**What exists and how is the accumulated conversational/analytical world spatially organized?**

### Timeline answers

**When did conversational participation and analytical development occur during this session?**

One canonical Thread may therefore have:

**one spatial identity + multiple Session Temporal Footprints.**

Repeated returns never create duplicate geography.

---

# A23. Session Live Head and Session Temporal Cursor

### Session Live Head

The actual current position of the live conversation.

### Session Temporal Cursor

The current-session time the user is inspecting.

When:

**Temporal Cursor = Live Head**

the user is inspecting the temporal present.

When:

**Temporal Cursor ≠ Live Head**

the user is inspecting an earlier position in the current session.

This temporal state remains separate from spatial camera behavior.

---

# A24. Follow Live Focus

**Follow Live Focus** is a separate spatial navigation intent.

Being temporally at the Live Head does not imply that the camera must follow Live Conversational Focus.

The user may:

- remain at Live Head;
- manually pan elsewhere;
- inspect another Thread;
- suspend Follow Live Focus;

without entering historical temporal inspection.

Therefore:

**Being at Live Head does not imply spatial auto-follow.**

---

# A25. Timeline → Map Behavior

Explicit Timeline navigation may reorient spatial inspection toward the canonical regions or objects truthfully applicable at the selected session time.

It changes:

- Session Temporal Cursor;
- temporal projection;
- potentially camera/navigation focus.

It never changes:

- canonical Home Anchors;
- canonical identities;
- accumulated world history.

---

# A26. Map → Timeline Behavior

Spatial navigation contextualizes the Timeline but does not automatically change the Session Temporal Cursor.

Navigating to a Thread may expose its relevant temporal footprints.

The user must explicitly select a temporal occurrence to change inspected session time.

Therefore Map↔Timeline synchronization is intentionally asymmetric:

**explicit temporal navigation may move spatial attention; spatial exploration exposes temporal relevance without automatically causing time travel.**

---

# A27. Historical Projection

Historical inspection creates a **time-valid projection of the accumulated canonical world**.

It may represent:

- what existed at that moment;
- what was conversationally active;
- what had already become analytically available.

It must not retroactively expose analytical knowledge that did not yet exist.

It also does not destroy or relocate canonical objects accumulated later.

A Thread established later may therefore possess a stable canonical Home Anchor in the accumulated world while being absent, Mention-only, or Emerging in an earlier temporal projection.

This is not a contradiction: the projection changes; canonical accumulated history does not.

---

# A28. Independent navigation states

The following remain conceptually independent:

1. **Live Conversational Focus**
   Where the live conversation is currently directed.
2. **Session Temporal Cursor**
   Which point in the current conversation is being inspected.
3. **Spatial/Semantic Inspection Focus**
   What part of the world/object the user is currently examining.
4. **Follow Live Focus**
   Whether spatial navigation is automatically following current conversational attention.

These states may legitimately point to different places simultaneously.

They must never be silently conflated.

---

# A29. Return operations

Two distinct recovery actions exist conceptually.

### Return to Live Time

Restores:

**Session Temporal Cursor → Session Live Head**

### Return to Current Focus / Follow Live

Restores spatial orientation/following toward:

**Live Conversational Focus**

Neither operation requires the other.

Neither changes canonical geography or erases recoverable navigation history.

---

# A30. Stage 0 Boundary

Stage 0 defines the **Experience Architecture**, not the final analysis grammar or runtime ontology.

Stage 0 intentionally does not freeze:

- final Thread type taxonomy;
- Event epistemic subclasses;
- discourse-relation taxonomy;
- final Grounded Semantic Relation taxonomy;
- Evidence Runtime ontology;
- detailed evidence-role taxonomy;
- final Unknown/Question taxonomy;
- confidence/calibration semantics;
- implementation schemas;
- storage models;
- spatial algorithms;
- morphology;
- colors;
- motion;
- visual styling.

Those decisions remain available to the appropriate later stages, beginning with Stage 1 where applicable.

# D. Final Stage 0 Freeze Candidate

The consolidated **QANDEEL Living Analysis Map — Experience Architecture v1** is internally consistent and ready for final Stage 0 closure with the following architecture locked as one system:

1. Conversation Threads represent persistent, independently addressable conversational attention rather than generic topics or model-generated interests.
2. Emerging Focus is provisional and has no permanent geography; persistent world geography begins only at Established Thread.
3. Established Threads preserve identity through Active, Dormant, and Reopened states.
4. Refinement may clarify a Thread without changing identity; genuine independently addressable reframing creates a new Thread.
5. Conversation World objects retain one canonical identity across zoom levels, Threads, temporal positions, and contextual representations.
6. Record/Utterance and Memory are source-bearing objects; Event is a grounded world object; Reading/Hypothesis, Unknown, and Question remain analytically distinct.
7. Evidence participation preserves the underlying canonical object without Stage 0 prematurely deciding Evidence runtime ontology.
8. Contextual Appearances enable one canonical object to participate in multiple Thread Neighborhoods without duplication.
9. Cross-Thread Shared Anchors are exceptional representations used only when shared identity itself is materially significant.
10. Every Established Thread receives one stable canonical Home Anchor in Conversation-World space.
11. Object Permanence applies to canonical world geography, not fixed screen pixels.
12. Conversational Origin guides outward growth but never mechanically determines geometric form.
13. Spatial proximity has no analytical meaning by default.
14. Conversation Transition, Grounded Semantic Relation, and Evidence Participation remain three separate contracts.
15. Conversation World growth is append-oriented; new information does not continuously rearrange established geography.
16. Thread convergence accumulates shared structure and relations without destructive merging.
17. Spatial, Conversational, Analytical, and Temporal structures remain independent even when they correlate.
18. Canonical world organization must not be determined by graph-force logic, semantic similarity, connection count, or relation structure; local non-semantic presentation physics remain permitted later.
19. Semantic Zoom changes representation and disclosed detail, never canonical identity or ontological truth.
20. Z0 = Conversation World; Z1 = Thread Neighborhood; Z2 = Analysis Object / grounding inspection; Z3 = Source Truth / inspectable provenance.
21. Deeper zoom reveals rather than rewrites, and Reading never becomes Source Truth.
22. Orientation preserves Spatial/Semantic Focus, Semantic Depth, Session Temporal Cursor, Session Live Head, Navigation Context, and Follow Live Focus state.
23. Inspection Lineage makes Z3 → Z2 → Z1 → Z0 reversible without assuming the world itself is a hierarchy.
24. Wayfinding requires Context Path, Focus History, World Overview, and persistent Thread landmarks without freezing their eventual visual controls.
25. Direct navigation addresses canonical objects while preserving contextual history and never inventing duplicate or arbitrary primary identities.
26. The primary Timeline is scoped only to the current conversation/session.
27. Session Temporal Position, Source/Referenced Temporal Origin, and Analysis Availability Time remain distinct.
28. One canonical Thread may have multiple Session Temporal Footprints without duplicate geography.
29. Session Live Head and Session Temporal Cursor are independent; temporal present does not imply spatial auto-follow.
30. Follow Live Focus is an independent spatial navigation intent that may be suspended while remaining at the temporal present.
31. Timeline navigation may reorient spatial inspection but never canonical geography; Map navigation exposes temporal relevance without automatically changing the Session Temporal Cursor.
