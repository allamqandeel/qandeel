## North Star

**QANDEEL Living Analysis Map — Conversation as an Unfolding Semantic World.**

The user explores one persistent semantic world. The world grows as conversation evolves, keeps spatial memory, supports Pan + Semantic Zoom, exposes session/analysis/source truth progressively, and never manufactures meaning through geometry.

Core experiential sentence:

> **I am still inside the same evolving human world, even when I move, zoom, inspect, switch context, or return.**

## Binding navigation principles

1. **Semantic Zoom ≠ Optical Magnification.** Every deeper level reveals newly appropriate semantic structure.
2. **Live Focus ≠ Inspected Focus.** The conversation may be happening elsewhere while the user inspects another place.
3. **Canonical Object Identity ≠ Contextual Appearance.** One object can appear in several legitimate contexts without duplication or ownership.
4. **Exact Return is real.** Return restores the prior object + context + semantic depth + inspection/camera state; it does not recompute or approximately relocate.
5. **Pan moves the camera through one persistent geography.** It never rearranges Home Anchors.
6. **Direct jumps land inside context, not in empty isolated screens.**
7. **Ordinary sharing ≠ Shared Anchor.** A Cross-Thread Shared Anchor is exceptional and requires independent spatial entitlement.
8. **Device change ≠ canonical reflow.** Narrow/mobile may show less context and stronger orientation aids, but the same geography persists.
9. **Navigation is not analysis.** Switching context or following a shared object must not invent a semantic relation.
10. **World → Thread → Session → Reading/Analytical Object → Source/Provenance** is a disclosure lineage, not a page hierarchy.
