# Open Decisions After Stage 4

These are intentionally **not frozen** by Stage 4:

- exact gesture vocabulary for mouse, trackpad and touch
- exact camera interpolation / easing / animation timing
- motion language and transition choreography (later Stage 12)
- whether minimap is always visible, adaptive, or optional
- exact visual component used for Context Lineage / Focus History
- retention length / pruning policy for inspection history
- exact thresholds for semantic-depth transitions
- collision/occlusion strategy at production scale
- performance architecture / renderer technology
- accessibility and keyboard-navigation implementation details
- final responsive projection rules beyond the frozen no-reflow principle
- exact copy and iconography for return/focus actions
- Timeline UI and Map↔Timeline behavior (Stage 5)
- Replay behavior (Stage 13)

These may be designed later only if they preserve the frozen Stage 0–4 contracts.
