# Next Stage Handoff

## Next major stage

**Stage 4 — Pan + Semantic Zoom Navigation**

Stage 4 should operate on the frozen Stage 3 world rather than redesign it.

### Core question

How does the user navigate the persistent Conversation World, pan between regions, move between World → Thread → Session → analytical/source depth, and recover orientation without recomputation or identity loss?

### Protected requirements entering Stage 4

- same canonical geography across views;
- Thread Home loci do not move;
- Semantic Zoom reveals meaning, not merely magnification;
- Session opens from within its Thread field;
- deeper inspection preserves lineage/orientation to Session → Thread → World;
- world does not become cards/panels at depth;
- contextual object appearances preserve one canonical identity;
- navigation cannot manufacture semantics;
- historical K(t) remains same world filtered by then-valid truth;
- interaction design may change disclosure/camera, not canonical meaning.

### Do not begin by choosing technology

No Canvas/SVG/WebGL/native decision should be treated as the Stage 4 starting point. Interaction contract and proof should precede implementation selection.
