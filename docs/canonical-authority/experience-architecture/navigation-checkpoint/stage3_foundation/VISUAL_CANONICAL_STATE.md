# QANDEEL Static Visual Language v1 — Canonical State

## 1. Governing visual truth

The frozen rule remains:

> **A visual relationship may be drawn only if it is true of the runtime / canonical analytical state.**

Visual form has no independent analytical authority. In particular:

- proximity does not mean relation or similarity;
- distance does not mean semantic distance;
- size does not mean importance, truth, confidence, or rank;
- brightness does not mean confidence, selection, success, or “AI active”;
- centrality does not mean “main topic”;
- direction does not mean causality/influence unless independently grounded;
- repetition does not multiply canonical identity or Evidence;
- enclosure/grouping must not silently manufacture ownership/hierarchy;
- lines/bindings require explicit entitled meaning or must be unmistakably presentation-only.

**QANDEEL Light = rare warranted significance/crystallization.** It is not generic glow, status, confidence, selection, success, activity, or decoration.

## 2. Stage 3.2 — World morphology — FROZEN

Canonical family: **Organic Living Field — Nebular World**.

Frozen:

- one continuous world, not isolated cards or nodes;
- nebular cognitive substrate: atmospheric depth and continuity, not literal astronomy;
- Established Thread reads as a persistent **place**;
- one stable perceptual Home locus per Established Thread;
- adaptive organic Neighborhood expression around the fixed locus;
- sparse/dense states remain the same place family;
- Dormant remains geographically present;
- Reopened means return to the same place;
- Emerging Focus is pre-geographic and must not read as a smaller Established Thread;
- relation removal must not collapse the world;
- Session footprints can exist inside Thread fields.

Not frozen:

- exact palette;
- exact contour geometry;
- exact field texture;
- exact micro-symbols/icons;
- final rendering technology;
- Pan/Zoom mechanics.

## 3. Sessions and session footprints — CARRIED FORWARD

User-facing requirement:

- session boundaries/footprints must be legible enough to understand that distinct conversational episodes exist inside a Thread;
- a long Session and an important/significant Session must not be conflated;
- if footprint extent is used for duration, that mapping must be explicit;
- significance/crystallization requires a separate bounded cue;
- deeper inspection must make Session content **more legible**, not more abstract.

A Session is not a Thread and has no Thread Home Anchor.

## 4. Stage 3.3 — Epistemic object grammar — FROZEN

A Session unfolds as **one local analytical field** whose contents emerge as materially differentiated formations native to the same living world.

Frozen broad epistemic distinctions:

- **Direct source-bound:** Record / CU;
- **Provenance-sensitive Memory:** Memory identity does not automatically mean direct Source Truth or Evidence;
- **Grounded world:** Event;
- **Analytical:** Reading;
- **Inquiry:** Unknown / Question.

Frozen:

- broad families must remain perceptually distinguishable without requiring taxonomy labels first;
- two peer Readings must not receive a visual winner/rank through size, glow, centrality, or proximity;
- direct/user-stated Memory and derived/processed Memory may differ through provenance-sensitive material treatment while remaining recognizably Memory-related;
- Session interior must not become a mini node graph / mind map / infographic;
- contents should feel like differentiated material layers/forms inside one local analytical space.

Not frozen:

- literal “paper/parchment” shape for direct CU/source;
- exact icon set;
- exact micro-morphology for each type.

## 5. Stage 3.4 — Relations, Evidence, Cross-context — FROZEN

Frozen distinctions:

- Grounded Semantic Relation (GSR);
- Evidence Participation;
- Thread Participation / Contextual Appearance;
- Cross-Thread impact;
- same canonical object across contexts;
- exceptional Cross-Thread Shared Anchor;
- Conversation Transition (history only, not semantic relation).

Core relation rule:

> **No truth → no connection.**

Cross-thread influence should be understandable as:

**source locus / session / event → grounded relation/influence current → local impact locus in receiving Thread**

rather than a generic Thread-to-Thread line.

### Evidence

Evidence Participation is not equivalent to a GSR. Thickness, brightness, count, proximity, or repetition may not become unsupported evidence strength/confidence.

### Shared canonical objects

Default:

> **MULTIPLE CONTEXTUAL APPEARANCES FIRST.**

One canonical Memory/Event may appear in Work, Ahmed, and Relationship-with-Ahmed while remaining one identity. Ordinary appearances must not create a fourth central hub, primary owner, Thread relation, extra Evidence, or corroboration.

Exceptional Cross-Thread Shared Anchor remains a materially stronger permanent spatial commitment and must remain rare and independently warranted.

## 6. Stage 3.5 — Visual state language — FROZEN

Canonical state rule:

> **State modifies an identity; state does not become a new identity.**

Frozen semantic distinctions:

- Active / Dormant / Reopened remain the same Thread family;
- Emerging Focus remains provisional/pre-geographic;
- ambiguity remains unresolved rather than spatially “chosen”;
- Current / Superseded / Retired remain the same Reading family;
- Unknown OPEN / RESOLVED / IRRELEVANT / SUPERSEDED are lifecycle states, not new object types;
- Historical ≠ false;
- Superseded ≠ never valid;
- Retired ≠ wrong;
- Dormant ≠ deleted;
- Reopened ≠ new Thread;
- current focus ≠ importance.

The state system should rely on material cohesion, formation, persistence, trace/patina, boundary behavior, resolution, etc., not primarily color/status badges.

**Exact hue mappings are NOT frozen.**

## 7. Stage 3.6 — Composition / density / depth — FROZEN

Frozen composition rules:

- a dense world must remain a world, not become a dashboard;
- spatial structure remains primary under realistic density;
- depth = disclosure/orientation, not rank/truth/confidence;
- long Arabic labels, Egyptian Arabic, formal analytical Arabic, dates/numbers, and Arabic-English code-switch must remain viable;
- device/view changes may reduce disclosure, clip, or change local label handling but may not create canonical reflow;
- spatial memory must survive across projections;
- a dense Thread is not automatically more important;
- relation-density is a selective-disclosure problem, not a reason to turn the world into a graph;
- reduced glow/decoration must not collapse the identity of the visual system.

### In-place Session disclosure — load-bearing freeze

Future deeper disclosure must preserve:

**World → Thread → Session → contents**

The Session opens **inside the Thread field** through a local semantic aperture / field bloom. The surrounding world may recede/soften/reduce detail, but the Session may not become a detached card, modal, drawer, report, or inspector panel.

## 9. Historical truth / K(t)

Historical projection is the same persistent world filtered to what was knowable/valid at time t.

It must not:

- reveal future Threads;
- reveal future Readings/relations/participations/Shared Anchors;
- backdate later correction;
- create a compact or re-centered historical layout.

Same world. Earlier truth.

## 10. Anti-drift / forbidden defaults

Reject any future direction that materially collapses into:

- dashboard/cards as the architecture;
- document/report/editorial analysis as the main experience;
- timeline-only analysis;
- mind map;
- Miro/Obsidian canvas;
- node/edge or knowledge graph;
- constellation/neural-network visualization;
- generic AI SaaS;
- sci-fi HUD / cyberpunk / VisionOS imitation;
- literal galaxy/planet/solar-system metaphor;
- literal terrain/island/city geography;
- decorative relationships without truth entitlement;
- generic glow as the visual identity.

A literal cosmic metaphor is rejected. The **nebular substrate is retained** as the ambient cognitive environment of the person's world.

## 11. User-authored product intent that must remain protected

The experience should feel like QANDEEL is progressively revealing the person's inner world, e.g. “the space of Nadia,” without claiming a literal model of the brain.

The user specifically requires:

- clearer Session presence/boundaries/footprints;
- important Sessions to become discoverable without equating duration with importance;
- truthful inter-Thread influence (e.g. Ahmed affecting Work) to be understandable;
- deeper Semantic Zoom to make each Session and its contents clearly inspectable;
- the world to remain visually rich, distinctive and emotionally compelling while avoiding generic AI-generated-interface aesthetics.
