# Anti-Drift + Non-Meaning Contract

## Do not turn QANDEEL into
- dashboard/card navigation
- page-stack mobile navigation
- browser tabs
- file-tree / folder hierarchy
- Miro / Obsidian graph
- generic knowledge-graph explorer
- generic AI SaaS
- sci-fi HUD / cyberpunk
- literal galaxy / astronomy UI
- literal terrain-map mimicry

The approved metaphor is a **persistent semantic world**, not a graph of nodes and not a report with navigation chrome.

## Navigation cues do NOT mean analytical truth
- Current Live Focus ≠ most important
- Inspected Focus ≠ most important
- Center of viewport ≠ important
- Dense region ≠ important
- Brightness/glow ≠ confidence or correctness
- Context switch ≠ semantic relation
- Same object in two Threads ≠ relationship between those Threads
- Frequent appearance ≠ additional evidence count
- Direct jump ≠ ownership
- Deeper zoom ≠ higher truth rank
- Historical ≠ false
- Dormant ≠ deleted
- Reopened ≠ new Thread

## Geometry remains analytically non-authoritative by default
Proximity, direction, centrality, size, overlap and placement cannot manufacture a semantic claim unless that specific visual relationship is canonically entitled.

## Proof-board scaffolding is not frozen UI
Some canonical reference boards use rectangular boxes, matrices, legends, labels and panel-like explanatory framing. These are **presentation scaffolds for proof**, not automatically product components.

What is frozen is the interaction truth shown by the images, not the explanatory poster layout.
